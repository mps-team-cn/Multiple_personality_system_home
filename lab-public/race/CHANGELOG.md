# Changelog

## [v2.0] — 2026-06-07 (当前版本)

### 新增

- **神话装备强化系统**：神话品质零件现在可以在「改装页 → 已装备零件」中强化，最高 +10。
- **后期金币消耗口**：强化费用会随等级提高，适合作为全神话后的长期养成目标。
- **强化成功率机制**：强化等级越高，成功率越低；失败只消耗金币，不会降级或损坏装备。
- **强化属性加成**：神话装备强化后会小幅提升核心正向属性。
- **强化成就**：新增「神话开刃」「十阶神装」「全神话共鸣」等成就。
- **彩蛋成就**：新增「晴川猫猫贴纸」「脸脸低电量省油包」两个轻量安慰型彩蛋。

### 规则

- 只有神话装备可以强化。
- 每件神话装备最高强化到 +10。
- 强化等级会保存到本地存档。
- 卸下装备后，强化等级仍然保留。
- 全神话 +10 成就按全部神话部件模板判断，每一种神话部件都需要至少一件达到 +10。

### 平衡

- 强化定位为后期成长和金币回收，不作为普通通关门槛。
- 强化失败不会降级，不会损坏装备。
- 强化收益加入分段递减，并按属性区分权重，降低纯马力堆叠收益，提高轮胎、变速和稳定类强化价值。
- 强化费用改为固定等级表，成功率按下一目标等级结算。

### 工程

- **TypeScript 改造启动**：逐步为 Race 的状态、零件、设置、成就和强化系统增加类型约束。
- **设置结构整理**：音效开关与信息收集开关统一纳入设置结构。

### 设置

- **信息收集开关**：新增「接受信息收集」开关，默认开启；关闭后不会发送游玩日志。
- **清理本地数据**：新增危险操作按钮，可清理本浏览器内的全部 Race 数据，包括存档、成就、神话强化和设置。
- **重开并清档语义调整**：重开并清档用于重置当前游戏进度，不再等同于清理全部本地数据。

## [v1.8.1] — 2026-06-07

### 优化

- **随机绿灯时机**：红灯保持 900ms，黄灯到绿灯改为 450-1600ms 随机等待，避免玩家按固定节奏抢起步。
- **轻量 beep 音效**：使用 Web Audio API 生成红 / 黄 / 绿灯、抢跑、胜利和失败短音，并在档案页提供本地保存的音效开关。
- **电脑也会反应一下**：绿灯后电脑不再瞬间起跑，会按难度有一小段起步反应；赛后战报会显示你的反应、电脑反应和谁先起步。
- **AI 托管起步节奏调整**：AI 托管的起步反应放慢到 0.22-0.40 秒，更像普通玩家托管一场，而不是极限秒踩。

## [v1.8] — 2026-06-07

### 优化

- **休闲 / 标准体验补丁**：下调休闲与标准模式电脑后期强度上限，降低装备未成型时的追赶压力。
- **连续失败软保底**：休闲连续失败 3 场、标准连续失败 4 场后，下一场会临时放宽对手强度。
- **练习赛恢复**：现金低于最低报名费时，主报名按钮会提示进入无报名费练习赛，提供低额奖金恢复参赛能力，不计正式连胜和高难度成就。
- **轻量配装提示**：商店与改装页增加当前短板提示，零件卡片会标出补短板方向或高风险竞速件。

### 规则

- **休闲低名次回收**：休闲模式第 5 名奖金保底提高到最低报名费的 70%，减少连续失败破产速度。
- **商店刷新规则**：切换难度不再刷新商店，比赛正常结束后刷新商店并使用当前难度奖池。
- **练习赛商店规则**：练习赛结束不刷新商店，避免免费练习成为免费刷商店入口。

## [v1.7] — 2026-06-07

### 新增

- **AI 托管一场**：新增单场托管入口，会自动报名、等待绿灯并按普通玩家级别的反应时间完成起步，保留完整赛道动画和赛后结算。
- **托管状态提示**：赛事战报区与结果提示区增加 AI 托管说明，并新增托管相关存档兼容字段。

### 规则

- **托管反应统一**：AI 托管不再随当前难度放慢，所有难度统一使用噩梦档反应时间。
- **高难度开局下限**：专家和噩梦加入电脑强度下限，避免开局直接切高难度套利。
- **操作类成就隔离**：AI 托管比赛可正常获得收益和比赛记录，但不会解锁反应、慢起步、抢跑、连胜、连续名次等依赖玩家操作的成就，也不会污染手动反应和手动连胜统计。
